# Tag

Een keuzepil voor filters en de beroepskiezer. Gekozen is `marine` met witte tekst; met `dot` krijgt de pil een stip die geel wordt als hij gekozen is.

- Jij levert de tekst, `active` en `onClick`. Gebruik `dot` voor beroepen en taken.
- Altijd minstens 44px hoog. Een groep tags krijgt `role="group"` en een `aria-label`.

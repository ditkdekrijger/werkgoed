# BeroepKiezer

Snel wisselen tussen beroepen: links op `marine` wat er in de praktijk gevraagd wordt, rechts in de beroepstint welke kleding en PBM daarbij horen.

- Jij levert `beroepen`: een lijst met `naam` (eindigt op "goed"), `beroep` (de tintsleutel, zoals `las`), `regel`, `eisen` (3 tot 5 korte regels), `pakket` (producttypes) en optioneel `href` naar de beroepspagina. Verder optioneel `defaultIndex`, `href` en `knop`.
- Eisen komen uit de praktijkkennis van Werkgoed en moeten door Werkgoed worden gecontroleerd voordat ze live gaan.
- Op de homepage staat de beroepenwand met `BeroepKaart`. Gebruik de kiezer waar ruimte krap is, zoals een categoriepagina of een mobiele lade.

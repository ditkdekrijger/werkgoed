# Zegel

Een rond stempel in oranje met tekst rondom en het W-blok in het midden. Werkgoed zet zijn naam onder een keuze.

- `tekst`: kort en klein, zoals "kennerskeuze", "kennerspakket", "pasvorm". Werkgoed en het merkteken zet de zegel er zelf bij.
- `size`: 28 (bij een uitleg), 64 (op een productkaart via `kenner`), 84 tot 120 (op een productfoto of pakket).
- `id`: uniek per zegel op de pagina.
- Maximaal één zegel per kaart en twee per scherm. Een zegel is een advies van Werkgoed, geen keurmerk of norm.

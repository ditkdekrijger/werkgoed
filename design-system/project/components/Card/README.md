# Card

Een vlak met `radius-card` voor inhoud die bij elkaar hoort. Geen schaduw.

- `tone`: `sunken` (kalk), `canvas` (warm werkkatoen), `surface` (wit met haarlijn), `marine` (donker, tekst `on-night`), `signal` (één per pagina, voor de belangrijkste oproep) en `vlam` (zachte oranje tint voor een let op).
- `beroep`: zet het vlak in de beroepstint, bijvoorbeeld `beroep="las"`.
- `night` werkt nog als alias van `marine`.
- Jij levert de inhoud als children.

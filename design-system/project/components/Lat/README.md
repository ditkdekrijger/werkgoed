# Lat

Een rij afgeronde latten, overgenomen uit de bovenkant van het W-blok. Het merkpatroon van Werkgoed en de scheiding boven de footer.

- Eén per pagina, over de volle breedte binnen de zijmarge, boven de footer of boven de showroom.
- `tone`: `vlam` (standaard), `marine` of `licht` (op marine).
- `height`: 16, 28 of 40. Decoratief, verborgen voor schermlezers.
- Vervangt de Streep op nieuwe pagina's. De Streep blijft bestaan voor afzetting en bouwplaatsthema's.

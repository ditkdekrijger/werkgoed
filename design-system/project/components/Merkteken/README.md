# Merkteken

Het W-blok uit het logo van werkgoed.nl: zes latten en een W in een afgerond vierkant. Het kleinste herkenbare stuk Werkgoed.

- Standaard in oranje. Met `tone="inherit"` neemt het de tekstkleur over.
- Gebruik het als afzender: naast een kicker op `marine`, bovenaan een advieskaart, in de kennerskaarten, als watermerk in een `FotoPlek`.
- Minimaal 20px. Nooit vervormen, draaien of in een andere vorm zetten.
- Props: `size`, `tone`, `label` (alleen als het teken los betekenis draagt).

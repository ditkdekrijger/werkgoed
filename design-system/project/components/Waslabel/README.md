# Waslabel

Specificaties en hulp in de vorm van het label binnenin een jas: een gestikte rand, het merkteken en regels met label en waarde.

- Jij levert `titel` (kleine letters, zoals "havep 50468"), `regels` (lijst met `label` en `waarde`) en optioneel `voet`.
- Gebruik het voor productspecificaties, normen, maattabellen en een korte keuzehulp.
- Waarden in smalle cijfers. Wat nog niet bekend is schrijf je als [CONTROLEREN], nooit verzonnen.

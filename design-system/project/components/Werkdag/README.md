# Werkdag

Een dag uit het leven van het beroep, van begin tot eind. Per moment: de tijd, wat er gebeurt, welke risico's spelen en wat je dan draagt. Zo laat Werkgoed zien dat het het werk kent, niet alleen de kleding.

- Jij levert `beroep` en `momenten`: een lijst met `tijd` ("07:00"), `titel`, optioneel `tekst`, `risicos` (namen uit `Icoon`) en `goed` (onderdelen uit het pakket).
- Vijf tot zeven momenten. Schrijf vanuit de vakman: "Je knipt de laatste stenen op maat."
- De tijden in de diepe beroepskleur, smalle cijfers. Op smalle schermen staat de tijd boven de tekst.

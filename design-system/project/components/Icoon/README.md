# Icoon

Voorlopige lijniconen op een 24-raster, lijn 1,5px, ronde uiteinden, kleur `currentColor`. Werkgoed heeft nog geen eigen set; vervang deze zodra die er is.

- Beroepen: `las`, `straat`, `bouw`, `techniek`, `magazijn`, `chauffeur`, `groen`, `schilder`.
- Risico's: `vonk`, `hitte`, `regen`, `kou`, `zicht`, `lawaai`, `stof`, `snijden`, `chemie`, `knielen`, `hoogte`.
- Assortiment: `jas`, `broek`, `schoen`, `handschoen`, `helm`, `voet`.
- Service en interface: `levering`, `voorraad`, `verzending`, `klok`, `telefoon`, `mail`, `locatie`, `advies`, `zoek`, `wagen`, `account`, `menu`, `sluit`, `omlaag`, `pijl`, `check`.
- Props: `naam`, `size` (standaard 24), `stroke`, `label`. Zonder `label` is het icoon decoratief en verborgen voor schermlezers. Met `label` krijgt het `role="img"`.
- Doe niet: emoji, gevulde iconen of iconen van andere merken.

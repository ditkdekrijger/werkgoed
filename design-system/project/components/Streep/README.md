# Streep

Diagonale band in `signal` en `marine`, het merkmotief van Werkgoed. Het verwijst naar werkkleding en afzetting.

- Maximaal één Streep per pagina, als scheiding boven de showroom of de footer, volle breedte.
- Decoratief: de component is voor schermlezers verborgen.
- `height` is standaard 16px. Gebruik 16, 24 of 32.

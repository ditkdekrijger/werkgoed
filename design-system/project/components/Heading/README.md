# Heading

Kop in Archivo 700 met breedte 90% en tracking -.03em. `size` kiest `mega` (alleen het beroepswoordmerk, breedte 80%), `display`, `h1`, `h2` of `h3`. Koppen breken gebalanceerd af.

`accent` zet één woord of de slotzin op een oranje markering. Zet `tone="night"` op `marine`, dan staat het accent als oranje blokje met marine tekst.

- Eén accent per kop, nooit in lopende tekst.
- Geen hoofdletters, geen gedachtestreepjes. Korte zinnen met een punt: "Past altijd goed."
- Jij levert: de tekst als children en optioneel `accent`. `as` verandert alleen het HTML-element.

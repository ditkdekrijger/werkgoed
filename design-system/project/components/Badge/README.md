# Badge

Klein label in pilvorm voor risico's, normen, kenmerken en een enkele aanbieding. Hier komt de steunkleur `vlam` tot leven, altijd klein.

- `tone`: `vlam` (aanbieding of "Hardloper", maximaal één per kaart), `risico` (op `vlam-soft`, met een risico-icoon), `norm` (normcode in `staal`, smalle cijfers), `outline` (een onderdeel uit het pakket), `signal` en `marine`.
- Optioneel `icoon`: een naam uit `Icoon`.
- Jij levert de tekst als children. Normcodes behouden hun eigen schrijfwijze ("EN ISO 20471"). Andere tekst zonder hoofdletters aan het begin van een woord, behalve namen.
- Doe niet: badges als knop gebruiken, of meer dan één `vlam`-badge in beeld.
